## 🚀 ความเชี่ยวชาญด้าน Web Development (Web Tech Stack)

เราเชี่ยวชาญการพัฒนาเว็บไซต์และเว็บแอปพลิเคชันแบบครบวงจร เพื่อรองรับการทำงานของระบบการเรียนรู้ออนไลน์ที่ทันสมัยและเสถียร

### **Frontend Development**
* **Languages & Frameworks:** HTML5, CSS3, JavaScript (ES6+), TypeScript, React.js, Next.js, Vue.js
* **Styling & UI:** Tailwind CSS, Bootstrap, Material UI, Styled Components
* **State Management:** Redux, Zustand, React Query

### **Backend & Database**
* **Server-side:** Node.js, Express.js
* **Database:** MongoDB, PostgreSQL, MySQL, Firebase (Realtime Database & Firestore)
* **API & Auth:** RESTful APIs, GraphQL, JWT Authentication, OAuth

### **Web-Based EdTech Tools**
* Web-based Interactive Canvas / Whiteboard APIs
* Real-time Classroom Technologies (WebSockets / Socket.io)
* Gamified Web UI & Animation Libraries (Framer Motion, Canvas API)
